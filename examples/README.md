## Understanding Report Quality

### What Makes These Reports "Institutional-Grade"?

**1. Data Integrity**
Every number sourced:
```
EPS: ₹45.20 [Source: Screener.in, 15 Mar 2026]
Not: "EPS is around ₹45"
```

**2. Forensic Rigor**
Always checks:
- CFO/PAT ratio (earnings quality)
- Accruals (revenue recognition games?)
- Receivables vs Revenue growth (collections issue?)
- Promoter pledging (distress signal?)

**3. Multi-Model Validation**
Never relies on single valuation method:
- P/E re-rating (market mood)
- EV/EBITDA (capital structure neutral)
- DCF (intrinsic value)
- Blended target with weights

**4. Scenario Planning**
Shows bull/base/bear explicitly:
```
Bull Case (30% prob): ₹3,500 (Everything goes right)
Base Case (50% prob): ₹3,150 (Central estimate)
Bear Case (20% prob): ₹2,600 (Key risks materialize)
```

**5. Actionable Specificity**
Not: "Stock looks good, consider buying"
Instead:
```
BUY in tranches:
40% at ₹2,800 (current level)
30% at ₹2,750 (S1 support)
30% at ₹2,700 (200-DMA)
Stop-loss: ₹2,600 (thesis invalidated)
```
